# 中文电子书常见排版问题速查

诊断时逐项对照。每项给出：特征（怎么认出它）、示例、修复要点。

## 1. 幽灵空格（断词空格）

**最伤阅读的问题，优先级最高。**

- 特征：正文里汉字之间被塞进半角空格，数量动辄几千处。正则是 `[\u4e00-\u9fff] [\u4e00-\u9fff]`。
- 成因：原书（PDF/MOBI/纸书 OCR）按固定栏宽硬换行，转换软件把换行符变成了空格。
- 示例：`"敏敏休学已经三 年了"` → 应为 `"敏敏休学已经三年了"`；`"内心非 常矛盾"` → `"内心非常矛盾"`。
- 修复：删除两侧都是中日韩字符/全角标点的空格（见 `scripts/fix_cjk_spaces.py`）。**不要**无脑删所有空格——汉字与数字/拉丁字母之间（如 `"ICU-21 床"`、`"OK 镜"`）以及纯拉丁词之间的空格要保留。

## 2. 页眉页码混入正文

- 特征：孤立的短段落，匹配 `^第[一二三四五六七八九十百零〇]+[章节部卷]\s*\d{1,4}$` 或纯页码 `^\d{1,4}$`，且前后是空段。
- 成因：纸书每页顶部的页眉（章名+页码）被当成正文段落提取。
- 示例：正文中突然冒出 `"第一章 011"`、`"第二章 041"`。
- 危害：页眉常把一句话拦腰截断——正文 A 段末尾是 `"...他从"`，页眉之后 B 段开头是 `"来没有陪我进去过医院"`，中间本该连成 `"他从来没有…"`。
- 修复：删掉页眉段及相邻空段；若 A 不以句末标点结尾（`。！？…"」』）)】〉》` 等），把 A、B **直接拼接**（不加空格——原文此处是换行不是空格）。注意别把真正的标题段误当成 A 拼接掉。
- 相关：注释被压平也会把句子截断、也呈“结尾无句末标点”的拆断形态，见 §11。

## 3. 段落首行无缩进

- 特征：CSS 中 `p { text-indent: 0 }`，或根本没有 text-indent 声明。
- 修复：正文段落设 `text-indent: 2em`（中文两字缩进）。题记、署名、日期、居中句、版权页等用 `.no-indent` 类取消缩进。

## 4. 无标题层级

- 特征：章/节标题是普通 `<p>`，没有 `<h1>/<h2>`；诊断脚本会报 `h1=0 h2=0`。
- 修复：重建时把章标题设为 `<h1>`、节标题设为 `<h2>`、部/卷用 `<h1 class="part">`，并加 `page-break-before: always` 让章另起页。

## 5. 目录损坏 / 缺失

- 特征：`toc.ncx` 的 navMap 只有一个 navPoint（常叫 "Start"），或根本没有 HTML 目录页。
- 修复：重建 HTML 目录页 + `toc.ncx`。navMap 按 部→章→节 正确嵌套，playOrder 从 1 连续递增。结构以正文实际标题为准，目录漏掉的节要补上。

## 6. 元数据错误

- 特征：`dc:language` 是 `en`；`dc:title` 缺失；`meta name="calibre:title_sort"` 是哈希值；`dc:creator` 缺失或 `file-as` 是 "Unknown"。
- 修复：`dc:language` 填 `zh-CN`，补全 `dc:title`/`dc:creator`/`dc:publisher`，去掉无意义的哈希排序键。

## 7. 空段落撑间距

- 特征：正文里大量 `<p> </p>`、`<p>&nbsp;</p>` 或 class 为 spacer 的空段（数量成百上千）。
- 修复：删掉所有空段，间距交给 CSS 的 margin。标题与正文的间隔用 `h1/h2` 的 margin 控制。

## 8. 结构识别（部/章/节）

识别章节目录的可靠顺序：
1. 先看纸质书目录页（正文开头）或原 `toc.ncx`，提取"第X章 + 标题 + 各节标题"。
2. 在正文里定位：标题通常是**前后都是空段的孤立短段落**。
3. 部/卷标记如"第一部""第二部"，常配一个地点名或一段引文题记（题记署名常见 `——某某`）。
4. 页眉里的"第X章 页码"可用来确认某段文字属于哪一章。

两个坑：
- **目录漏节**：正文里有而目录没有的节标题（例如正文有"驱逐2"但目录只写了"驱逐1"）——按正文实际补上。
- **重名地名**：同一个地名既是部名又是后面的节名（如"滨海市"），靠出现顺序和上下文消歧，别简单按名字匹配。

## 9. 打包合法 EPUB 的硬性要求

- `mimetype` 文件内容必须是 `application/epub+zip`，且是 zip **第一个条目**、**不压缩**（`ZIP_STORED`）。阅读器靠它识别格式。
- 包内必须有 `META-INF/container.xml`，指向 `content.opf` 的 `full-path`。
- 所有 XHTML/OPF/NCX 必须能被 XML 解析器解析（正文里的 `&`、`<`、`>` 要转义）。
- 打包后自检：mimetype 首项且 STORED、zip 完整性（`testzip()`）、正文无残留幽灵空格和页眉。

## 10. 中文排版细节备忘

- 正文：宋体/思源宋体系字体，行高 1.8–2.0，两端对齐，首行缩进 2em。
- 标题：居中，部 > 章 > 节逐级缩小字号；章标题前 `page-break-before: always`。
- 题记/引文：左右各缩进（如 `margin: 0 1.5em`），不缩进，可用灰色；署名右对齐。
- 日期（日记体）：不缩进、可加粗。
- 数字与汉字之间一般不加空格；拉丁词与汉字之间保留一个空格。

## 11. 注释（脚注）被压平进正文

- 特征：正文里出现圈号标记 `① ② ③`，同时有以圈号开头的段落（`①抑郁症，也被称为抑郁障碍……`）被当成普通正文段落。
- 成因：纸书页脚的注释在转换时被当作正文提取，插进了正文流。
- 危害：注释段落把句子截断；编号按**页**从 ① 重新开始，全书多处重复，不能当唯一 ID。
- 修复：转成 **EPUB3 弹出式脚注**——正文标记换成 `<a epub:type="noteref" href="#fnN" id="fnrefN">N</a>`，注释收进该章末尾的 `<section epub:type="footnotes">`，每条一个 `<aside epub:type="footnote" id="fnN">`，并带回链。`<html>` 要声明 `xmlns:epub="http://www.idpf.org/2007/ops"`。用 `scripts/fix_notes.py` 一键完成（默认弹出式 + 自动升级 EPUB 3）；标记样式自动识别圈号 `①`/方括号 `[1]`/`注N`/圆括号 `（1）`/星号 `*`，也可 `--marker-style` / `--marker-regex` 指定。
- 细节：
  - 一条注释可能被换页拆成两段（`①脱敏治疗……降低个体焦虑` + `反应的行为疗法。`）：后段不以句末标点结尾即是续文，要拼接。
  - 以“——编者注”收尾的注释是完整的，别误并到下一段。
  - 编号按**章内顺序**重排（改用数字或 `[N]`），避免跨页重复。
