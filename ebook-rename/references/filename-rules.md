# 文件名清洗规则（详细）

本文件解释 `scripts/rename_ebooks.py` 的清洗规则、正则与边界情况。SKILL.md 只给速查表，遇到拿不准的书名看这里。

## 1. 副标题

在**最早出现**的副标题分隔符处截断，保留分隔符之前的部分：

| 分隔符 | 例 |
| --- | --- |
| `：` 全角冒号 | `叫魂：1768年中国妖术大恐慌` → `叫魂` |
| `:` 半角冒号 | `安史之乱 : 历史、宣传与神话` → `安史之乱` |
| `—` / `——` / `–` | `XXX——副标题` → `XXX` |
| ` - ` | `FIREPUNCH炎拳 - 卷01` → 见第 4 节（保留分卷） |

只在**位置 > 0** 时截断，避免书名以冒号开头时被清空。

注意：有些“冒号后面”其实不是副标题，而是书名的有机组成部分（例如 `图解Skill：AI提效实战指南`）。通用规则仍会截断，此时用 `--overrides` 指定 `{"match": "^图解Skill：", "title": "{raw_title}"}` 保留全名。

## 2. 简介 / 丛书 / 版本说明（括号）

从**第一个** `(`、`（`、`【`、`[` 起整段丢弃（同样只在位置 > 0 时生效）：

| 原书名 | 结果 |
| --- | --- |
| `1929年大崩盘 (华安基金世界资本经典译丛)` | `1929年大崩盘` |
| `我的前半生：全本【贝托鲁奇电影原著】` | `我的前半生`（先被冒号截断） |
| `摄影的艺术(彩印)` | `摄影的艺术` |
| `恐怖分子的洋伞（曾经让你…）读客悬疑文库` | `恐怖分子的洋伞` |

代价是书名里本来就有括号的（如 `哈利·波特（纪念版）`）会一起丢掉——按“只保留书名”的目标，这是可接受的。

## 3. 站点广告 / 水印

正则 `_AD_RE` 匹配并删除：`t.me/…`、`tg@…`、`z-library.*`、`1lib.*`、`annas-archive.*`、`libgen.*`、以及 `@xxx.com|net|sk|org` 形式的句柄。这些常直接混在 `dc:title` 里（如 `某某手册 tg@sharebooks4you`）。

## 4. 系列名与分卷

- **系列/册数**：书名里形如 `·全13册（附概念民国1册）`、`·第3卷` 的尾段整段丢弃。
  例：`不一样的中国史·全13册（附概念民国1册）` → `不一样的中国史`。
- **分卷保留**：识别 `第2卷`、`卷02`、`卷二`、`Vol.2`，把它从书名中取出、单独规范化后附回末尾：
  - `卷01` → `第01卷`
  - `第2卷`、`卷二`、`Vol.2` 原样（去空格）
  - 例：`FIREPUNCH炎拳 - 卷01` → `FIREPUNCH炎拳 第01卷`

  保留分卷是关键：否则同一套漫画各卷会被压成同一个名字，改名时全部撞车。

  注意 `全13册` 走的是“系列丢弃”而不是“分卷保留”，因为它是总册数而非当前卷号。

## 5. 作者

- 全角间隔号统一：`约翰•肯尼斯•加尔布雷思` → `约翰·肯尼斯·加尔布雷思`；` · ` 两侧空格去掉。
- 多作者分隔符 `,`、`/`、`、`、`;`、`；` 统一成 `, `：`张诗坪 / 胡可奇` → `张诗坪, 胡可奇`。
- 去重：结尾括号内容与前面重复时删掉括号部分，`陶涵 [陶涵]` → `陶涵`。
- **国别/朝代前缀默认保留**：`[美] 孔飞力`、`【韩】金敬哲`、`（英）查尔斯·麦凯`、`[清] 爱新觉罗·溥仪`。加 `--strip-author-prefix` 可去掉，得到 `孔飞力` 等。
- 作者字段是协作者名单时不特判（如 `藤本樹,龍幸伸,瓜生愛美`），需要只留主作者就用 overrides 指定 `author`。

## 6. 文件名安全

替换 Windows/通用文件系统非法字符 `\x00-\x1f / \ : * ? " < > |` 为 `_`。**中文全角标点保留**：`：`（全角冒号）在文件名里合法，且能保住书名语义，所以 `图解Skill：AI提效实战指南(宝玉).azw3` 是允许的。若目标文件系统不支持，改用 overrides 把 `：` 换成别的。

中间后缀 `.bak` 之类的保留：`要有光（梁鸿）.bak.epub` → `要有光(梁鸿).bak.epub`。

## 7. 幂等性

脚本按**元数据**生成目标名，与当前文件名无关。因此对同一批书反复运行结果一致（第二次显示“待改名 0 个”）。overrides 也按 metadata 匹配，同样幂等。这是刻意设计：改名这类操作经常需要分批、反复执行。

## 8. 冲突与跳过

以下情况**跳过并在报告中列出**，绝不覆盖已有文件：

- 两个文件清洗后目标名相同；
- 目标文件名已存在于目录中；
- 元数据里既没有 `dc:title` 也没有可回退的标题。

## 9. 为什么不处理 PDF

PDF 的文档信息（`/Title`、`/Author`）实测大量为空、为软件默认值，或是 `TOP杂志网www.Topzazhi.com` 这类水印，XMP 也常缺失。用它们改名会得到比原文件名更糟的结果。若用户坚持，只能退化为解析文件名，并明确告知不可靠。
